# easyos-save-confirm-pp4mnk.sh
EasyOS Save Confirm by pp4mnk adds a preview to the session save dialog in RAM mode. It lists new and modified files still pending in RAM and skips caches, logs, temporary files, and changes already included in the prepared copy. Review the list before saving or discarding changes when you use Save, shut down, or restart EasyOS Excalibur.

----------------------------------------------------------

ENGLISH.- 
After several hours at the computer, I reach the EasyOS shutdown dialog and realise I can no longer remember what I changed, what I already saved, or what is still in RAM. I may have edited a script, adjusted the desktop, tested a launcher, and clicked **Save** somewhere in between. By the end of the day, all those changes tend to blur together. I wanted the save prompt to show me enough information to make that decision while I still had the session open.

**EasyOS Save Confirm** adds a review window to the existing save dialog. When I choose to save or leave without saving, the script lists the relevant changes and asks me to confirm. I can return to the original dialog. If I spot a configuration file I meant to keep, I can change my mind before shutting down. If I only see changes from an experiment I meant to discard, I can proceed with more confidence.

I made two versions for different situations.

**Original version for detailed review.** This version shows every entry it detects in the session layers it checks. That includes new files, modified files, files copied into RAM, deletions, and replaced directories. It also shows which entries are already in the prepared copy and which appear only there. I use this version when I want to inspect the whole picture, including changes generated by applications and the system. It is useful when I am testing something and want to see which files it affected.

**Basic version for everyday use after long sessions.** This version is designed to show the files I created or changed myself. It focuses on new and modified files still pending in places such as my home directory, `/etc`, and the directories for local scripts and launchers. It skips background activity such as caches, logs, temporary files, and most browser profile changes. It also leaves out files that already match the saved session or the prepared copy. The filter works from file paths and file comparisons, so an application can still produce a change that appears in the list.

That difference matters after a long session. I might have used **Save** earlier, then edited a script again. The basic view helps me spot that later edit. The original view gives me more context about what was already prepared. EasyOS still handles the save itself, including the copy it can prepare when I use the **Save** icon. The script gives me a chance to review the information before confirming.

Both versions are available in English and Spanish. They were designed for EasyOS Excalibur 7.5.4 and require Python 3 and YAD. To try the English basic version, run `sh easyos-save-confirm-pp4mnk-en.sh --install`. Use `--preview` to open the list separately or `--uninstall` to restore the original EasyOS dialog.

For me, the useful part is being able to finish the day without relying on memory alone. I can see what changed, recognise the files I care about, and decide what to carry into the next session.

ESPAÑOL

Cuando llevo varias horas delante del ordenador, a veces llego al momento de apagar EasyOS y no recuerdo qué he cambiado, qué he guardado y qué sigue en RAM. Durante la sesión puedo haber retocado el escritorio, editado un script, probado un lanzador y pulsado **Save** en algún momento. Al final del día, me resulta difícil distinguir qué cambios estaban ya en la copia preparada y cuáles hice después. De ahí surgió **EasyOS Save Confirm**.

El script añade una ventana de revisión al cuadro de guardado de EasyOS. Cuando elijo guardar o salir sin guardar, puedo ver el listado y confirmar mi decisión. También puedo volver al cuadro anterior. Por ejemplo, si pensaba descartar los cambios de una prueba y veo que he modificado un archivo de configuración que quiero conservar, todavía estoy a tiempo de revisarlo y cambiar de decisión.

**Versión original o detallada.** Muestra todas las entradas que detecta en las capas de sesión que examina. Incluye archivos nuevos y modificados, archivos copiados a RAM, eliminaciones y carpetas reemplazadas. También indica qué entradas están ya en la copia preparada y cuáles figuran únicamente allí. Es la versión que uso cuando estoy probando algo y quiero ver qué ha cambiado en la sesión, incluidos los cambios generados por las aplicaciones y el sistema.

**Versión básica o normal.** Está pensada para el uso diario y para encontrar los archivos que he creado o modificado. Muestra los cambios pendientes en rutas como mi carpeta personal, `/etc` y las carpetas de scripts y lanzadores locales. Deja fuera cachés, registros, archivos temporales, gran parte de la actividad de los navegadores y archivos que coinciden con la sesión guardada o con la copia preparada. El filtro se basa en las rutas y en la comparación de archivos, de modo que también puede aparecer algún cambio realizado por una aplicación.

La diferencia se aprecia cuando ya he pulsado **Save** y después vuelvo a editar un archivo. La versión básica me ayuda a localizar ese último cambio. Si quiero saber qué contenía la copia anterior, puedo consultar la versión detallada. El guardado lo sigue gestionando EasyOS. Al usar el icono **Save** durante la sesión, el sistema puede preparar una copia para incorporarla más tarde. La ventana de confirmación me permite revisar los cambios antes de tomar la decisión.

Las dos versiones están disponibles en español y en inglés. Están diseñadas para EasyOS Excalibur 7.5.4 y requieren Python 3 y YAD. Para instalar la versión básica en español, se puede ejecutar `sh easyos-save-confirm-pp4mnk-es.sh --install`. La opción `--preview` abre el listado por separado y `--uninstall` restaura el cuadro de diálogo original de EasyOS.

Lo que más valoro es poder revisar los cambios con la sesión todavía abierta. Si hay un archivo que no esperaba encontrar, puedo abrirlo y comprobar qué pasó. Si veo los cambios que quería conservar, puedo confirmar el guardado con una idea más clara de lo que me llevaré a la siguiente sesión. Después de horas de trabajo, agradezco poder decidir con la lista delante.
